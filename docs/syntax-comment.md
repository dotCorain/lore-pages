# 注释

使用 `%` 开头来书写注释。注释在生成的 HTML 中会变成 `<!-- -->` 注释。

## 语法

```
% 注释内容
```

- `%` 后面**必须跟一个空格**。
- `%` 后不加空格不会被识别为注释（会变成段落）。

## 示例

```
# 页面标题

% 这是一条注释，不会在页面上显示。

## 内容

这是可见的内容。
```

## 渲染结果

```html
<h1>页面标题</h1>

<!-- 这是一条注释，不会在页面上显示。 -->

<h2>内容</h2>

<p>这是可见的内容。</p>
```

## 转义

如果你想在段落中使用字面量的 `%`，使用转义写法：

```
这段文字包含 \\% 百分号。
```

渲染后：

```html
<p>这段文字包含 % 百分号。</p>
```

## 自定义注释符

在 `Lore.toml` 中可以自定义：

```toml
[parser]
comment_key = "//"
comment_key_escape = "\\//"
```

这样 `// 注释` 就会成为注释语法。
