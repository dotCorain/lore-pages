# 标题

标题使用 `#` 前缀，支持 1~4 级。

## 语法

```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

## 规则

- `#` 和内容之间**必须有空格**。
- `#` 的数量决定标题级别（1~4）。
- 超过 4 个 `#` 的行不被识别为标题，会回退为段落。
- 不加空格的 `#NoSpace` 也不被识别为标题。

## 正确示例

```
# 页面标题

## 第一小节

## 第二小节

### 子小节
```

## 错误示例

```
#NoSpace       → 会被当作段落，不会变成标题
##### 太多了    → 超过4个 #，也会被当作段落
```

## 渲染结果

| 输入 | HTML 输出 |
|------|----------|
| `# Title` | `<h1>Title</h1>` |
| `## Section` | `<h2><a href="Section/index.html" class="link_lore">Section</a></h2>` |
| `### Sub` | `<h3>Sub</h3>` |
| `#### Deep` | `<h4>Deep</h4>` |

## H2 自动链接

H2 标题会被自动赋予链接属性，指向 `{标题名}/index`。这意味着每个 H2 标题在 HTML 中是可点击的，点击后跳转到对应的子页面。

这一行为由 `Category::auto_link_h2()` 实现，在渲染前自动完成。你不需要在 `.lore` 文件中额外写链接。
