# 图片

使用 `|` 前缀来插入图片。

## 语法

```
| 图片URL
```

- `|` 后面**必须跟一个空格**。
- 渲染为 `<img src="URL">` 标签。

## 示例

```
# 截图

| https://example.com/screenshot.png

图片上方可以加说明文字。
```

## 渲染结果

```html
<h1>截图</h1>

<img src="https://example.com/screenshot.png">

<p>图片上方可以加说明文字。</p>
```

## 注意事项

- 图片使用与外部链接**相同的标记符** `|`，区别在于：
  - **图片**：行首是 `| `（空格后没有名称部分），渲染为 `<img>`
  - **外部链接**：中间有 ` | `（名称+空格+`|`+空格+URL），渲染为 `<a>`

- 如果想在段落中使用字面量的 `|`，需要用转义 `\\|`。

## 自定义符号

在 `Lore.toml` 中：

```toml
[parser]
image_key = "!"
image_key_escape = "\\!"
```

这样可以用 `! https://...` 来插入图片。
