# 分隔线与占位符

## 分隔线 (BreakLine)

使用 `---` 来插入分隔线。

### 语法

```
---
```

- 默认是**三个短横线** `---`，可通过 `Lore.toml` 中的 `breakline_key` 修改。
- 行首必须严格匹配 `---`；`--`（两个短横线）不会匹配。
- 渲染结果为一个 `<br>` 标签。

### 示例

```
## 第一节

一些内容。

---

## 第二节

更多内容。
```

### 渲染结果

```html
<h2>第一节</h2>
<p>一些内容。</p>
<br>
<h2>第二节</h2>
<p>更多内容。</p>
```

## 占位符 (Placeholder)

使用 `_` 开头行来插入占位符。占位符**不会渲染**为任何 HTML 内容。

### 语法

```
_ 占位内容
```

- `_` 后面**可以不跟空格**。
- 渲染时产生空字符串（不输出任何内容）。

### 用途

占位符可以用于：

- 预留未来要添加的内容位置
- 作为分隔标记（开发时可见，发布时不可见）

### 示例

```
# 计划

_ TODO: 添加更多内容

已经完成的部分。
```

## 自定义符号

在 `Lore.toml` 中可以自定义：

```toml
[parser]
breakline_key = "***"
breakline_key_escape = "\\***"
placeholder_key = "~"
placeholder_key_escape = "\\~"
```
