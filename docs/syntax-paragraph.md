# 段落

任何不匹配其他语法模式的行都会被当作**段落**处理。

## 规则

- 完全空白（或只有空白字符）的行会被保留为 `EmptyLine` 节点。
- 非空白、不匹配模式的行直接成为段落。
- 如果段落中包含转义序列（如 `\\|`），转义会被还原为字面量字符。

## 示例

```
这是一段普通的文字。

这是另一段文字，中间隔了一个空行。

这段包含逃逸的 \\| 管道符和 \\= 等号。
```

## 渲染结果

```html
<p>这是一段普通的文字。</p>

<p>这是另一段文字，中间隔了一个空行。</p>

<p>这段包含逃逸的 | 管道符和 = 等号。</p>
```

## 注意事项

- 段落**不支持**行内格式（没有粗体、斜体等）。Lore Pages 追求简单，格式靠 CSS 控制。
- 如果你想在段落中使用 `|`、`=` 等标记字符作普通文本，需要使用转义写法（如 `\\|`）。
