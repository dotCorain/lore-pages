# 语法参考

Lore 是一种**面向行**的标记语言。每一行要么匹配某个语法模式，要么被视为一个段落。

## 基本规则

1. 每一行独立解析。行首的 `#`、`%`、`|` 等标记决定该行的类型。
2. 空行（或纯空白行）被保留为 `EmptyLine` 节点。
3. 不匹配任何模式的行被当作**段落**处理。
4. 逃逸序列（如 `\\|`）可以让标记符号在段落中作为普通文本显示。

## 语法一览

| 语法 | 示例 | 说明 |
|------|------|------|
| 标题 | `## 小节标题` | `#` ~ `####`，生成 `h1` ~ `h4` |
| 段落 | `这是一段文字。` | 任何不匹配其他模式的行 |
| 外部链接 | `文档 \| https://example.com` | 渲染为 `<a>` 链接 |
| 内部链接 | `首页 = index` | 链接到同项目的其他页面 |
| 注释 | `% 这是注释` | 转为 HTML `<!-- -->` 注释 |
| 分隔线 | `---` | 生成 `<br>` |
| 占位符 | `_ 内容` | 不渲染，用于预留位置 |
| 图片 | `\| https://example.com/a.png` | 生成 `<img>` 标签 |
| 折叠块展开 | `- 笔记 > https://...` | 引用外部 URL 的折叠块（默认展开） |
| 折叠块收起 | `+ 笔记 > https://...` | 引用外部 URL 的折叠块（默认收起） |
| 折叠块展开(lore) | `- 笔记 = path` | 引用 Lore 页面的折叠块 |
| 折叠块收起(lore) | `+ 笔记 = path` | 引用 Lore 页面的折叠块 |
| 转义 | `\\\|` | 在段落中显示字面量 `\|` |

详细说明请参阅各子页面。
