# 介绍

**Lore Pages** 是一个用 Rust 编写的轻量级静态网站生成器。

它将自定义的 `.lore` 标记语言编译为纯 HTML 网页，适合用作：
- 个人 Wiki / 知识库
- 项目文档站点
- 笔记整理与发布

## 设计理念

Lore Pages 追求**简洁、可配置、可扩展**：

- **简洁**：`.lore` 语法极简，几分钟即可上手。一行文本就是一个段落，`#` 开头就是标题。
- **可配置**：所有标记符号（链接分隔符、注释符等）都可以在 `Lore.toml` 中自定义。
- **可扩展**：基于 trait 的架构，你可以替换解析器（Parser）或渲染器（Renderer），支持未来输出 PDF、JSON 等格式。

## 快速体验

先看一个 `.lore` 文件的例子：

```
# 我的知识库

## 编程语言

Rust 是我最喜欢的语言。

官网 | https://www.rust-lang.org
笔记 = rust-notes

## 数学

% 下面是一段笔记
微积分是研究变化率的分支。

---
```

编译后变成结构化的 HTML 页面，H2 标题自动附带链接，`---` 变成 `<br>`，`%` 变成 `<!-- -->` 注释。

## 架构概览

```
.lore 源文件
    │
    ▼
┌─────────┐
│ Parser  │  解析为 Anchor 节点列表
└────┬────┘
     │
     ▼
┌──────────┐
│ Category │  中间表示（IR）
└────┬─────┘
     │
     ▼
┌──────────┐
│ Renderer │  渲染为 HTML
└────┬─────┘
     │
     ▼
  .html 文件
```

四个核心模块：

| 模块 | 路径 | 职责 |
|------|------|------|
| **IR** | `src/ir/` | 定义 `Anchor`（节点）和 `Category`（文档）两种数据类型 |
| **Parser** | `src/parser.rs` | 将 `.lore` 文本解析为 `Category` |
| **Renderer** | `src/render.rs` | 将 `Category` 渲染为 HTML |
| **Framework** | `src/framework/` | 提供 trait 抽象和配置加载 |

## 与其他工具的比较

| 特性 | Lore Pages | Markdown | reStructuredText |
|------|-----------|----------|------------------|
| 学习曲线 | 极低 | 低 | 中等 |
| 链接语法 | `名称 \| url` | `[名称](url)` | 多种格式 |
| 可配置标记符 | ✅ | ❌ | ❌ |
| 折叠块 | ✅ 原生支持 | ❌ | ❌ |
| 可替换后端 | ✅ trait 架构 | ❌ | ❌ |
