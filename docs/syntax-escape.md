# 转义

当你需要在段落中显示标记符号的字面量（而非触发语法解析）时，使用**转义序列**。

## 默认转义表

| 想要显示的字符 | 写法 |
|--------------|------|
| `\|`（管道符） | `\\\|` |
| `=`（等号） | `\\=` |
| `%`（百分号） | `\\%` |
| `---`（三个短横） | `\\---` |
| `_`（下划线） | `\\_` |
| `-`（在行首时） | `\\-` |
| `+`（在行首时） | `\\+` |
| `>`（在折叠块中） | `\\>` |

## 工作原理

转义在**解析阶段**生效：

1. 当一行被识别为**语法元素**（链接、注释等）时，只在名称和值部分进行转义处理。
2. 当一行**不匹配任何模式**被当作段落时，所有配置的转义序列都会被还原。

换句话说：你不需要在链接的 URL 中转义（它已经是 URL 了），只需要在**段落**中转义。

## 示例

### 段落中的转义

输入：

```
如果想用管道符 \\| 做分隔，需要转义。

同样，等号 \\= 也需要转义。

百分号 \\% 也是。

三个短横 \\--- 也可以正常显示。
```

渲染结果：

```html
<p>如果想用管道符 | 做分隔，需要转义。</p>

<p>同样，等号 = 也需要转义。</p>

<p>百分号 % 也是。</p>

<p>三个短横 --- 也可以正常显示。</p>
```

### 链接中的转义

如果链接的**名称**或**值**中包含标记符号，转义同样生效：

输入：

```
管道 \\| 符号 | https://example.com
```

解析结果：链接名称为 `管道 | 符号`（转义后的字面量 `|`）。

## 自定义转义符

转义符与对应的标记符绑定。如果你自定义了标记符，转义符也要同步修改：

```toml
[parser]
url_link_key = "->"
url_link_key_escape = "\\->"
```

这样在段落中写 `\\->` 就会显示字面量 `->`。

## 行首转义

如果一个段落以标记符开头（比如你想让第一行显示 `%`），有两种方式：

1. 使用转义：
   ```
   \\% 这不是注释，而是以百分号开头的段落。
   ```

2. 自定义配置让标记符不起作用（不推荐，会影响所有文件）。
